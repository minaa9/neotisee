Présentation finale

Projet mené seule, de l’analyse du besoin à la mise en ligne ; les deux fondatrices valident chaque étape.

Le site est validé quand…

  • les pages et contenus prévus sont intégrés
  • les fonctionnalités retenues marchent
  • les tests sont réussis et les corrections faites
  • l’association a approuvé le résultat
  • les fondatrices savent utiliser le back-office

Néotisse · Présentation client

J’ai porté le projet seule, en tant que cheffe de projet digital, et les deux fondatrices ont validé chaque étape. Le site n’est validé qu’une fois que les fondatrices peuvent modifier elles-mêmes le calendrier et les actualités.
