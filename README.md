# Néotisse — Expérience digitale

**Conception et développement d'un site web immersif pour l'association Néotisse.**

## À propos du projet

Néotisse est une association spécialisée dans l'archéologie expérimentale et la valorisation des textiles anciens, du Néolithique au Moyen Âge.

Ce projet consiste à concevoir et développer une nouvelle expérience digitale permettant de présenter l'association, ses activités, ses ateliers et ses événements.

L'objectif est de proposer un site moderne, immersif et intuitif, qui valorise les savoir-faire textiles et facilite l'accès aux informations pour les professionnels comme pour le grand public.

## Objectifs

- Valoriser l'identité et les activités de l'association.
- Présenter les ateliers, les événements et les actualités.
- Proposer une expérience utilisateur fluide et intuitive.
- Développer une identité visuelle originale.
- Concevoir une interface responsive adaptée à tous les écrans.

## Direction artistique

Le projet explore un univers visuel inspiré de la nature, des matières textiles et de l'histoire.

La direction artistique s'appuie sur :
- Des compositions éditoriales.
- Des photographies immersives.
- Des textures et formes organiques.
- Une typographie élégante.
- Des animations et interactions subtiles.

## Installation

Cloner le dépôt :

```bash
git clone https://github.com/minaa9/neotisee.git
```

Accéder au dossier du projet :

```bash
cd neotisee/docs
```

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement :

```bash
npm run dev
```
